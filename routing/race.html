Method. 48 caller scenarios against a 12-tool catalog and 8 ordered routing rules. Both lanes receive the same conversation, the same caller state, and the same routing spec. Jev answers one Choice question over the catalog; the LLM uses function calling with the spec in context. Per-decision latency and token cost were recorded live against the real APIs, then replayed here on a shared clock. Latency is end-to-end API time from one US machine, not model inference time. Rows tinted red picked the wrong tool. Caveat: the same author wrote the scenarios and the correct answers, so read the accuracy column as context rather than as a score. The latency and cost figures do not depend on those labels.
